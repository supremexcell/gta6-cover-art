Sunset Heist turns a photo and a caption into GTA 6-style cover art: multi-panel posters with bold lettering, a Vice City sunset/neon grade, six filters inspired by every GTA series, illustration levels that make the photo look more like an in-game screenshot, and a wanted level with gold stars. It exports PNG in 1080×1080, 1080×1350 and 1920×1080. It runs offline in a desktop browser from static files — photos never leave the machine. You can also open app/index.html directly, no server needed.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
